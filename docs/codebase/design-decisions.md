# Design Decisions

[Back to Codebase Guide](index.md)

A design decision is a rule that is not obvious from the code: breaking one
gives results that are wrong but look correct. Each area has one page, and each
rule names where it lives and the test that guards it. Before you change an
area, read its page only.
