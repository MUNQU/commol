# ModelBuilder API

[Back to API Reference](index.md)

Builds a `Model`. A `StratificationCondition` selects the compartments of a
category or of a set of categories, and a `StratifiedRate` gives a transition its rate in the
compartments that match its conditions. Guide:
[Building Models](../guide/building-models.md), [Transitions](../guide/transitions.md).
