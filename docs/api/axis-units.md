# AxisUnits API

[Back to API Reference](index.md)

Converts values in units to steps of a model axis, gives the rate that an
engine reads from a mean span or a probability over a period, and gives the
window grid of a width in a unit. Guide:
[Units of the axis](../guide/core-concepts.md#units-of-the-axis).
