The pages also document names that are not in the package root:

- The scores are the module `commol.scores` (`from commol import scores`), on the [Uncertainty](https://munqu.github.io/commol/latest/api/uncertainty/#scores-and-intervals) page.
- `LossFunction`, the values of `CalibrationProblem.loss_function`, is in `commol.context.constants`.
- `UnitConsistencyError` is in `commol.utils.equations`.
- Some types are only read from what a method returns, and you do not import them: `InitialCompartment` (an entry of `Aggregate.initial_state()`), the blocks of a `ModelDescription`, the parts of an `IdentifiabilityReport`, and the types of a model in [Model Structure](https://munqu.github.io/commol/latest/advanced/model-structure/index.md).
