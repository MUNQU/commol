# API Reference

[Back to Home](https://munqu.github.io/commol/latest/index.md)

Every public name of `commol`, generated from the docstrings. The guide pages explain how to use them; these pages list every argument, attribute and error.

The package root `commol` holds the main flow: build a model, choose its structure, simulate it and calibrate it, as in `from commol import Simulation`. Every other name lives in the module of its page of the guide, as in `from commol.resampling import BayesianBootstrap`; each module has its page here. A name you only read is not exported: a result is typed as the return of the member that gives it, and it is on the page of that object, as `SimulationResults` is on the Simulation page. A choice among names is a string, such as `loss_function="sse"`.
