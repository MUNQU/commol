# API Reference

[Back to Home](https://munqu.github.io/commol/latest/index.md)

Every public name of `commol`, generated from the docstrings. The guide pages explain how to use them; these pages list every argument, attribute and error.

The table lists each name that the package root exports (`commol.__all__`), on the page that documents it. Import these names from the package root, as in `from commol import Simulation`. A name you only read is not exported: a result is typed as the return of the member that gives it, and it is on the page of that object, as `SimulationResults` is on the Simulation page. A choice among names is a string, such as `loss_function="sse"`.

The pages also document names that are not in the package root:

- The scores are the module `commol.scores` (`from commol import scores`), on the [Uncertainty](https://munqu.github.io/commol/latest/api/uncertainty/#scores-and-intervals) page.
- `UnitConsistencyError` is in `commol.utils.equations`.
- The types of a model, such as `ModelStructure`, the type of `Model.structure`, are in [Model Structure](https://munqu.github.io/commol/latest/advanced/model-structure/index.md).
