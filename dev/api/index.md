# API Reference

[Back to Home](https://munqu.github.io/commol/latest/index.md)

Every public name of `commol`, generated from the docstrings. The guide pages explain how to use them; these pages list every argument, attribute and error.

The package root `commol` holds the main flow: build a model, choose its structure, simulate it and calibrate it, as in `from commol import Simulation`. Every other name lives in the module of its page of the guide, as in `from commol.resampling import BayesianBootstrap`; each module has its page here. Every class that a public member returns is exported too, so a typed function names it, as in `def fit(...) -> CalibrationResult` with `from commol import CalibrationResult`. A result of the main flow is in the root, and the others are in the module of their page, such as `commol.resampling.BootstrapResult` and `commol.description.ModelDescription`. A result is on the page of the object that returns it or of its module, as `SimulationResults` is on the Simulation page. A result is the return of its member, not a class to build. A choice among names is a string, such as `loss_function="sse"`.

The pages also document names that no module exports, because no public member returns them:

- The bases `ModelStructure` (of `Aggregate`), `LocalResult` (of `LaplaceResult` and `SandwichResult`) and `ConformalMethod` (of the conformal methods) are under the path of their module.
- `InitialConditions`, whose fields and methods `Aggregate` holds, is in [Model Structure](https://munqu.github.io/commol/latest/advanced/model-structure/index.md).
