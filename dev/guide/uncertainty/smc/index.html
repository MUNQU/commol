    Sequential Monte Carlo: Gibbs Posteriors and ABC¶

    Back to Uncertainty

    These methods give a posterior of the parameters with no noise model. The Gibbs posterior turns the loss of the calibration into a posterior; ABC (approximate Bayesian computation) keeps the parameters whose runs come close to the data. Use them when you can state priors but not how the observations scatter around the model. One sequential Monte Carlo (SMC) sampler runs both, in parallel in Rust (crates/commol-inference/src/smc/), through Calibrator.uncertainty. The same sampler runs BayesianPosterior, the posterior of observation models, when you can state how the observations scatter.

    Quick path¶

    import numpy as np

from commol import (
    AbcSmc,
    Aggregate,
    CalibrationParameter,
    CalibrationProblem,
    Calibrator,
    EtaCalibration,
    GibbsPosterior,
    LossDistance,
    ModelBuilder,
    NelderMeadConfig,
    ObservedDataPoint,
    Priors,
    Simulation,
)


def flow_model(engine: str):
    """A flow c from A to B each step: absolute, since the rate names A."""
    return (
        ModelBuilder(name="Flow")
        .add_bin(id="A", name="A")
        .add_bin(id="B", name="B")
        .add_parameter(id="c", value=None)
        .add_transition(id="t_ab", source=["A"], target=["B"], rate="c * A / A")
        .build(
            Aggregate(bin_amounts={"A": 1000, "B": 0}),
            engine=engine,
        )
    )


# The flow of each of 30 steps, 10 plus a noise of sd 1.
rng = np.random.default_rng(1)
flows = 10.0 + rng.normal(0.0, 1.0, 30)
problem = CalibrationProblem(
    observed_data=[
        ObservedDataPoint(at=step, output="B", value=float(value), window=1)
        for step, value in enumerate(flows, start=1)
    ],
    parameters=[
        CalibrationParameter(id="c", parameter_type="parameter", min_bound=0.0, max_bound=30.0)
    ],
    loss_function="sse",
    optimization_config=NelderMeadConfig(max_iterations=500),
    seed=3,
)
calibrator = Calibrator(Simulation(flow_model("DifferenceEquations")), problem)

gibbs = calibrator.uncertainty(
    GibbsPosterior(
        priors=Priors.uniform_on_bounds(),
        eta=EtaCalibration.information_matching(),
        particles=500,
        target_cess=0.5,
        resample_threshold=0.5,
        stay_probability=0.05,
    )
)
print(round(gibbs.eta, 2))  # 0.73: 1/(2σ̂²), with σ̂² the mean squared residual
lower, upper = gibbs.sample.interval(0.9)["c"]
print(lower < float(np.mean(flows)) < upper)  # True

# ABC on the same data, from the chain binomial: each run draws its own flows.
stochastic = problem.model_copy(update={"replicates": 1, "replicate_summary": "mean"})
abc = Calibrator(Simulation(flow_model("StochasticSteps")), stochastic).uncertainty(
    AbcSmc(
        priors=Priors.uniform_on_bounds(),
        distance=LossDistance(),
        particles=300,
        target_cess=0.5,
        min_acceptance=0.05,
        stay_probability=0.05,
    )
)
print(abc.levels[0] > abc.levels[-1])  # True: the tolerance falls
print(abc.diagnostics.notes[0][:44])  # Each distance reads one fresh replicate of t

    Priors¶

    Every method of this page takes its priors with no default: what you know about each parameter before the data is a modelling choice. Give a mapping of parameter to distribution, or Priors.uniform_on_bounds(). A parameter without a prior, or a prior of a parameter that is not calibrated, raises a ValueError that names it.

    Each distribution is truncated to the bounds of its parameter:

    Distribution Density Bounds it needs
    Uniform() Uniform on the bounds Finite
    LogUniform() ∝ 1/x on the bounds: log x is uniform Finite, lower above 0
    Beta(a=…, b=…) Beta, scaled to the bounds Finite
    Normal(mean=…, sd=…) Normal, truncated Any
    LogNormal(mu=…, sigma=…) log x normal, truncated to (0, ∞) too Upper above 0
    Gamma(shape=…, rate=…) Gamma of mean shape / rate, truncated to (0, ∞) too Upper above 0

    A prior whose bounds do not fit raises a ValueError that names the parameter, its bounds and the distributions that fit them: a parameter in [0, inf] takes Normal, LogNormal or Gamma, not Uniform. Each distribution has log_density(x, bounds), cdf(x, bounds), quantile(p, bounds) and sample(count, bounds, seed). A draw inverts the distribution function of a number of the commol generator, so a seed gives the same draws on every platform.

    from commol import Gamma, Normal

bounds = (0.0, 30.0)
print(round(Normal(mean=10.0, sd=2.0).cdf(10.0, bounds), 3))  # 0.5
draws = Gamma(shape=4.0, rate=0.4).sample(3, bounds, seed=1)
print(all(0.0 <= draw <= 30.0 for draw in draws))  # True
priors = Priors(distributions={"c": Normal(mean=10.0, sd=2.0)})

    How the sampler works¶

    The sampler draws particles particles from the priors, runs the model at each, and keeps one value per particle: the loss for a Gibbs posterior, the distance for ABC. Each step then:

    1. Chooses the next level. The level is a temperature from 0 (the priors) to 1 (the posterior), or an ABC tolerance that falls. The next one is the farthest whose conditional effective sample size (Zhou, Johansen and Aston 2016) is target_cess of the particles, by bisection.
    2. Reweights each particle from the value it keeps. No model runs.
    3. Resamples (systematic) when the effective size falls below resample_threshold of the particles.
    4. Moves every particle by random-walk Metropolis, in parallel, each from its own stream of the generator. The walk proposes on an unbounded scale: the logit of the position between two finite bounds, log(θ − a) with a lower bound a only, log(b − θ) with an upper bound only, the parameter itself with none; so no proposal leaves the bounds. Its covariance is that of the particles on that scale, times 2.38² / d. If the first move accepts a share a of its proposals, the step moves every particle ⌈log c / log(1 − a)⌉ times (Drovandi and Pettitt 2011), with c the stay_probability: each particle moves at least once with probability 1 − c.
    Setting Meaning Larger values
    particles The size of the sample Less Monte Carlo error, more runs
    target_cess The share of the particles each step keeps More, smaller steps
    resample_threshold Resample below this share of effective size (Gibbs only) More resampling
    stay_probability The chance that a particle does not move in a step Fewer moves per step

    None of them has a default: each sets the cost and the accuracy of the run.

    Gibbs posterior¶

    GibbsPosterior samples π(θ) ∝ prior(θ) · exp(−η · loss(θ)), where loss is the problem's loss with its weights and normalization. It returns a GibbsResult: the sample at temperature 1, the temperatures, the log of ∫ prior(θ) exp(−η loss(θ)) dθ, the diagnostics, the η it ran with, the fit a calibration of η read (fit), and the coverage of a bootstrap calibration (coverage).

    What η means¶

    η weighs the data against the priors. The loss has no scale of its own, so η has no default: with η too large the posterior is too narrow, with η too small too wide. For the sum of squares of a model with Gaussian noise of variance σ², η = 1/(2σ²) makes the Gibbs posterior the Bayesian posterior.

    eta How it is chosen Needs Cost
    A number above 0 By you Nothing One sampler
    EtaCalibration.information_matching() η = tr(J I⁻¹ J) / tr(J) at the fit: the curvature J of the loss terms against their variance I (Holmes and Walker 2017) loss_function="sse", a deterministic engine A fit, finite differences and one sampler
    EtaCalibration.bootstrap_coverage(replicates, block_length, confidence_level) The posteriors of Bayesian-bootstrap data sets hold the fit at confidence_level (Syring and Martin 2019) Any loss and engine A fit and one sampler per replicate, then one

    Information matching is cheap and local; it needs a sum of smooth terms, so "rmse" (a square root of a sum), "mae" (no curvature) and a stochastic engine raise a ValueError that points to the other choices. Bootstrap coverage runs one tempered sampler per replicate to a large η, reads the posterior of every smaller η by reweighting, so its search runs no model, and finds for each replicate and parameter the η where the interval stops holding the fit. η interpolates those thresholds at the level, so the expected coverage is the level; it needs at least 1/(1 − c) − 1 replicates times parameters.

    With a stochastic engine the loss reads the problem's replicates with common random numbers, as the optimizers do, so it is a function of the parameters.

    With observation models the loss is the negative log-likelihood, so the Gibbs posterior is the fractional posterior prior(θ) · L(θ)^η, and η = 1 is the posterior of BayesianPosterior. η is a number or EtaCalibration.bootstrap_coverage(...); EtaCalibration.information_matching() needs a loss and raises a ValueError.

    ABC¶

    AbcSmc keeps a particle when the distance between its run and the data is at most a tolerance ε, and lowers ε step by step (Del Moral, Doucet and Jasra 2012). With weights of 0 or 1, the share of the particles that a tolerance keeps is its conditional effective sample size, so each next tolerance is the weighted quantile of the current distances at target_cess: the smallest distance whose share of the weight at or below it reaches it. The run stops when the first move of a step accepts less than min_acceptance, and keeps the sample of the tolerance before; it also stops when no lower tolerance keeps target_cess of the particles, as with whole numbers that tie. diagnostics.stop_reason says which.

    distance Value
    LossDistance() The problem's loss_function, with its weights and normalize_observations; a problem with observation models has none, so it raises a ValueError
    SeriesDistance(metric="rmse") or "mae" metric of each series on its residuals divided by the root mean square of its observed values, then the largest over the series

    SeriesDistance compares series in different units on one scale: scaling a series and its prediction by a constant leaves its distance unchanged, so the series of large values does not decide alone.

    With a stochastic engine each distance runs one fresh replicate, seeded from its particle's stream, and the particle keeps that distance until a move replaces it: that is what makes ABC sample its target. The problem's replicates and replicate_summary do not apply, and diagnostics.notes says so. The problem still needs them, since every calibration of a stochastic engine does.

    AbcRejection(priors, distance, draws, quantile) is one step of the same code with no move: it draws from the priors and keeps the closest share quantile of the draws.

    from commol import AbcRejection

rejection = calibrator.uncertainty(
    AbcRejection(
        priors=Priors.uniform_on_bounds(), distance=LossDistance(), draws=400, quantile=0.1
    )
)
kept = [weight > float("-inf") for weight in rejection.sample.log_weights]
print(sum(kept))  # 40

    Reading the diagnostics¶

    Field One entry per What to look for
    levels Step A Gibbs posterior ends at 1; an ABC run lists its falling tolerances
    diagnostics.effective_sizes Step Kish's effective size after reweighting; near target_cess of the particles
    diagnostics.resampled Step Whether the step resampled
    diagnostics.acceptance_rates Step The share of the first move's proposals accepted; a small one means many moves
    diagnostics.move_counts Step How many times each particle moved; it grows as the acceptance falls
    diagnostics.evaluations Run The number of model runs
    diagnostics.stop_reason Run Why the run stopped before its last level, or None
    log_evidence Run The log of the product of the mean incremental weights
    kept Particle The loss or distance each particle keeps 
    print(gibbs.levels[-1])  # 1.0
print(len(gibbs.diagnostics.move_counts) == len(gibbs.levels))  # True

    A step whose acceptance rate is small moves each particle many times, and the run costs more; more particles or a larger target_cess make the steps smaller. A sample whose effective size is small gives intervals with a large Monte Carlo error.

    Checklist¶

    • [ ] Each calibrated parameter has a prior you can defend, on bounds that fit it.
    • [ ] η is a number you can justify, or one of its calibrations.
    • [ ] A Gibbs posterior ends at temperature 1; an ABC run says why it stopped.
    • [ ] With a stochastic engine, ABC reads one replicate per particle, not the problem's summary.
